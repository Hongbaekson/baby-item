# 상품 검색과 공식몰 링크 갱신

업데이트: 2026-09-08 (KST)

## 장애 원인

네이버 개발자센터의 쇼핑 검색 API는 2026-07-31 종료됐으며 API HUB에도 대체 API가 없다. 운영 수집은 `404 SE05`로 실패했고, 마지막 네이버 데이터(2026-07-30 UTC)의 판매 근거가 30일 후 만료되면서 모든 구매 버튼이 닫혔다. [네이버 공식 공지](https://developers.naver.com/notice/article/32530)

종료된 수집 스크립트와 매일 호출하던 작업, API 키 의존성을 제거했다. 자동 가격 수집은 현재 제공하지 않는다.

## 공개 링크 정책

- 모든 상품은 `config/product-search-queries.json`의 브랜드·모델·규격 검색어를 사용한다. 광고 문구와 중복 표현은 제거하고 모델 번호·분유 단계·용량·대여 조건은 유지한다.
- `search` 상태의 네이버 검색은 판매 확인이나 재고 보장이 아니다. 확인 시각을 만들지 않으며, 공식몰 근거가 없거나 만료돼도 검색은 계속 제공한다.
- `verified` 상태는 HTTP 응답, 허용 도메인, 판매 종료 문구, 기대 상품명 전체 토큰을 확인한 공식 상품 페이지에만 적용한다. 30일 후에는 화면에서도 상품 검색으로 전환한다.
- 일반 상품명만 기록된 제품은 동일 모델을 특정할 수 없으므로 상세 화면에서 모델·용량·구성을 확인하도록 안내한다.
- 쿠팡 직접 링크와 이미지 요청은 계속 차단한다. 외부 네이버 검색 결과 자체의 판매처 구성은 이 사이트가 통제하지 않는다.
- 사이트 내부 검색은 띄어쓰기·기호·단어 순서 차이를 처리한다.

## 가격 계층

| 계층 | 조건 | 표시 |
| --- | --- | --- |
| `purchaseOffers` | 상품·재고·배송비 포함 총액·신뢰 도메인 검증 | 48시간 안이면 확인 가격 |
| `candidateOffers` | 상품 후보이며 배송비 또는 재고 미확인 | 날짜를 표시한 비클릭 참고 정보 |
| `rejectedOffers` | 상품 불일치·부속품·유통기한·가격 이상 등 | 비클릭 검토 정보 |

과거 네이버 가격의 `syncedAt`은 다시 찍지 않는다. 검증된 가격을 새로 확보하려면 수동 후보를 작성하고 `npm run price:apply-candidates`로 반영한다. 단순 검색 링크를 가격 검증 근거로 승격하지 않는다. 정책은 `config/offer-policy.json`과 `scripts/lib/offer-policy.mjs`에 있다.

## 수동 점검

```bash
npm run links:refresh
npm run links:check
npm run data:check
npm run price:check-strict
```

`links:refresh`는 등록된 공식몰을 조회하고 성공한 링크의 확인 시각만 갱신한다. 실패한 링크는 즉시 확인 시각을 비워 검색으로 전환하고 다른 상품 처리는 계속한다. 실패 상세는 `data/purchase-link-live-report.json`에 남긴다. 개별 실패를 명령 실패로 확인하려면 `npm run links:probe-official -- --strict`를 실행한다. 어떤 명령에도 네이버 API 키가 필요하지 않다.

## 자동 운영

`price-candidates.yml`은 기존 파일명을 유지하고 매일 03:17 KST와 수동 실행에서 다음을 수행한다.

1. 공식몰 실응답 검사와 실패한 링크의 근거 해제
2. 공식몰·검색 링크 정책 적용과 데이터 보고서 생성
3. 링크·데이터·가격 정책 검사, 테스트, 프로덕션 build
4. 검증된 세 파일만 `main`에 자동 커밋
5. OCI catalog-sync 타이머가 데이터 전용 커밋을 앱 컨테이너에 배포

검사 job은 읽기 권한만, artifact 적용 job은 `contents: write`만 추가로 가진다. 공식몰 일부 실패는 해당 링크에만 반영하며 데이터·테스트·build 실패는 발행을 중단한다. Edge와 서버의 별도 Caddy 설정은 유지한다.

빌드는 HTML에 공식몰 점검 시각과 공식몰·검색 링크 수를 넣는다. 운영 smoke는 HTTP 200뿐 아니라 점검 시각이 48시간 이내인지, 전체 상품 수와 링크 수가 일치하는지도 확인한다. 화면도 점검이 지연되면 이를 표시한다. 갱신이 멈춰도 상품 검색은 이용 가능하다.
