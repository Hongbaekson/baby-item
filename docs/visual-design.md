# 비주얼·접근성 기준

업데이트: 2026-07-26 (KST)

## 방향

밝고 아기자기한 분위기는 유지하되 제품 탐색과 구매 정보의 신뢰성을 우선한다. 장식은 카테고리 아이콘, 플레이스홀더, 작은 배지에 제한한다.

## 핵심 팔레트

| 용도 | 색상 |
| --- | --- |
| 배경 | `#fff8f3` |
| 표면 | `#ffffff` |
| 주요 텍스트 | `#3f3430` |
| 보조 텍스트 | `#6b5f59` |
| 코랄 버튼 | `#b54b42` |
| 코랄 강조 | `#96372f` |
| 경고 | `#f8b84e` |
| 검수 필요 | `#b33f3f` |

기존 밝은 코랄과 흰 글자 조합은 대비가 부족했으므로 더 짙은 코랄을 사용한다. 상태는 색상뿐 아니라 `가격 다시 확인`, `참고 후보`, `검토 필요` 같은 텍스트로도 전달한다.

## 레이아웃

- 제품 카드는 데스크톱 3열, 태블릿 2열, 모바일에서는 124px 이미지와 정보 영역을 나눈 가로형 1열이다.
- 첫 화면에는 9개만 노출하고 사용자가 원할 때 9개씩 더 불러와 초기 탐색 길이를 줄인다.
- 모바일 카테고리는 높이를 차지하는 여러 줄 grid 대신 가로 스크롤 한 줄을 사용한다.
- 모바일 헤더는 브랜드, `내 찜`, 테마 전환을 두 행으로 배치해 작은 화면에서도 각 버튼에 44px 터치 영역을 확보한다.
- 이미지 비율을 고정해 이미지 유무에 따라 카드 높이가 흔들리지 않게 한다.
- 카드에는 대표 구매 버튼 하나만 두고, 구매처 도메인을 버튼 안에 함께 표시한다.
- 상세 모달의 후보·제외 결과·데이터 이슈는 접힌 상태로 시작하고, 모바일에서는 최신가 확인 버튼을 화면 하단에 고정한다.

## 탐색 상태

- 검색, 카테고리, 정렬, 찜 전용 보기와 열린 상품은 URL query에 보존한다.
- 상세 모달은 브라우저 뒤로 가기로 닫을 수 있고 상품 URL을 그대로 공유할 수 있다.
- 찜 목록은 로그인 없이 현재 브라우저의 localStorage에 저장한다.
- 검색 결과가 없을 때는 필터를 한 번에 초기화하는 행동을 제공한다.

## 가격 표현

- 기록 가격은 `기록가`라고 명시한다.
- 검증 가격도 48시간 안인 경우만 `최저가`라고 표시한다.
- 배송비 미확인 검색 결과는 `참고 후보`이고 대표 CTA로 사용하지 않는다.
- 차단 후보는 검토 사유와 함께 비클릭 정보로 보여 준다.

## 접근성 완료 조건

- 검색 입력과 이미지 상세 버튼에 접근 가능한 이름이 있다.
- 검색어 삭제, 찜, 정렬, 더 보기 버튼에도 문맥을 포함한 접근 가능한 이름이 있다.
- 상품 이미지는 제품명을 포함한 대체 텍스트를 사용한다.
- 카테고리 선택 상태는 `aria-pressed`로 전달한다.
- 모달은 열릴 때 닫기 버튼으로 포커스를 옮기고, `Escape`로 닫히며, 포커스를 내부에 가둔다.
- 모달이 닫히면 원래 상품 버튼으로 포커스를 복원한다.
- 모달 배경은 `inert` 처리하고 body 스크롤을 잠근다.
- 키보드 포커스는 항상 눈에 보인다.
- `prefers-reduced-motion`에서는 불필요한 전환을 제거한다.
- 제휴 고지는 푸터와 상세 모달에 모두 표시한다.
- Playwright와 axe로 데스크톱·모바일을 자동 검사한다.
